## What is Metadata Cleaner?

Photos can contain additional information that you might not realize is there.

For example:

- Camera information
- Author information
- Location / GPS information
- Software information
- Date and EXIF information

**Metadata Cleaner** gives you a simple way to clean supported metadata from an image before sharing it.

No complicated settings.

Just:

**Choose → Clean → Check → Done.**

## How to use

### 1. Choose your image

Click **Choose File** and select an image.

### 2. Clean it

Click:

`EXECUTE METADATA`


### 3. Find your cleaned image

The cleaned version is automatically saved next to the Original File.

For example:

```text
vacation.jpg
vacation_cleaned.jpg
